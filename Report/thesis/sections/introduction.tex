\section{Introduction}
Type theory is a family of foundational systems, many based on a dependently typed $\lambda$-calculus.
The Curry-Howard correspondence links proofs and programs and allows theorem provers like
Coq, Agda, Scala, Lean etc. powered by type theories, to assist in machine-checking proofs
in a constructive and computational framework.~\cite{howard1995formulae}
In this report, we shall describe (intensional) instuistionistic Martin-L\"of Type Theory, Homotopy Type Theory and Cubical Type Theory in brief detail.
