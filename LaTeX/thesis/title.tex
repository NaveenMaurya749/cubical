  \begin{abstract}
    This report surveys three foundational frameworks in modern type theory: Martin-Löf Type Theory (MLTT), Homotopy Type Theory (HoTT), and Cubical Type Theory. Beginning with MLTT, it outlines its constructive, dependently typed foundation and the propositions-as-types paradigm. It then examines HoTT, highlighting its homotopical interpretation of types, identity types as path spaces, and key principles such as univalence and higher inductive types. Finally, the report introduces Cubical Type Theory, emphasizing its cubical set model and improved computational properties, including canonicity and normalization. Together, these perspectives illustrate the evolution of type theory toward a unified, computationally robust foundation for mathematics and formal reasoning.
  \end{abstract}
