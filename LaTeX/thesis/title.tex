  \begin{abstract}
    We survey three foundational frameworks in modern type theory: (intensional) Martin-L\"of Type Theory (MLTT), Homotopy Type Theory (HoTT), and Cubical Type Theory.
    We begin with an outline of Martin-L\"of Type Theory's deductional system based on depedent $\lambda$-calculus.
    Then, we describe the general framework of \emph{inductive types}, and describe standard inductive types and type formers, along with the
    \emph{W-Types} framework for custom instuctive types.
    We then examine the homotopical intepretation of type theory given by HoTT, identity types as path spaces, the univalence axiom and the concept of Higher Inductive Types (HITs).
    We discuss the limitations of HoTT towards HITs, and introduce Cubical Type Theory. 
    Finally, we describe the \emph{cubical category} and \emph{cubical sets}, to 
    conclude with Cubical Type Theory exhibiting improved computational properties such as univalence as a theorem, canonicity and normalization.
  \end{abstract}
